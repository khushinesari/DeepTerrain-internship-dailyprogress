## Final Scoring Pipeline

### For every candidate camera:

1. Raycast using the camera parameters to generate the exact FOV.
2. From that FOV, compute:
        - route intersections and intercepted route fractions,
        - newly visible terrain cells,
        - overlap with existing camera coverage,
        - frontier expansion,
        - visibility confidence from the raycasting results,
        - terrain importance using the terrain intelligence map.
3. Derive:
        - route_score from intercepted route geometry,
        - coverage_score from the FOV-derived coverage metrics.

4. Apply the strategy weights from strategy_iter_i.json:

```
final_score = route_weight   × route_score + coverage_weight × coverage_score
 ```
5. Select the highest-scoring camera, update the global coverage map, remove the observed routes, regenerate the terrain summary, and continue to the next iteration.
