# Bug Report: Agent 2 Data Validation Issue
## The Issue
Agent 2 is currently failing to return valid data when LLM responses are incomplete. Even when the majority of the data is correct, the agent is defaulting to placeholder values, leading to a loss of useful information.

## Root Cause
The validation logic was configured to be too strict.
- It required all 9 keys to be present in the LLM response.
- If even a small subset (specifically reasoning and priority_reasoning) was missing, the system discarded the entire response and reverted to default values.

## Proposed Fix
Instead of relying solely on strict code validation, we will update the system prompt to explicitly instruct the LLM to provide all required keys. This will reduce the likelihood of missing fields and prevent the validation logic from discarding valid data.

# environment_update.py logical implementation 

Purpose:

* Place the selected camera permanently
* Maintain runtime state
* Update cumulative FOV
* Remove compromised routes
* Save environment state
* Generate visualization for next iteration

Inputs:

* best_camera.json
* current_routes.json (paths_1.json for iteration 0, remaining_routes.json later)
* terrain_mask.npy
* obstacle_mask.npy

Runtime Folder:
agentic_ai/runtime_state/

Files maintained:

* fov_mask.npy
* placed_cameras.json

Iteration Folder:
runtime_state/iteration_N/

Generated:

* camera_N_mask.npy
* blocked_routes.json
* remaining_routes.json
* environment_state.json
* updated_environment_iter_N.png

Workflow:

1. Create runtime_state if missing.

2. If fov_mask.npy does not exist:
   runtime_fov_mask = np.zeros_like(terrain_mask)

3. If placed_cameras.json does not exist:
   placed_cameras = []

4. Load best_camera.json.

5. Assign:
   camera_id = len(placed_cameras) + 1

6. Generate camera mask using the exact build_fov_mask()
   from visibility_evaluator.py.

7. Save:
   camera_N_mask.npy

8. Append camera to placed_cameras.json.

9. Update cumulative FOV:
   runtime_fov_mask =
   np.maximum(
   runtime_fov_mask,
   camera_mask
   )

10. Save runtime fov_mask.npy.

11. Route elimination:

    For each route:

    ```
    visible = False

    For each (r,c):

        if camera_mask[r,c]:
            visible = True
            break

    if visible:
        blocked_routes.append(route)
    else:
        remaining_routes.append(route)
    ```

12. Save:
    blocked_routes.json
    remaining_routes.json

13. Coverage:

    covered =
    np.sum(
    runtime_fov_mask &
    terrain_mask
    )

    total =
    np.sum(
    terrain_mask
    )

    coverage_percent =
    100 * covered / total

14. Save environment_state.json

{
"iteration": N,
"placed_cameras": len(placed_cameras),
"routes_before": len(routes),
"routes_removed": len(blocked_routes),
"routes_remaining": len(remaining_routes),
"coverage_percent": coverage_percent,
"blind_spot_percent": 100 - coverage_percent
}

15. Visualization:

RGB Image:

Terrain:
Green

Obstacle:
Red

Runtime FOV:
Yellow

Remaining Routes:
Blue

Camera:
Magenta

Camera Label:
White text

For every camera in placed_cameras:

```
draw magenta marker

draw label:
    C1
    C2
    C3
```

16. Save:

updated_environment_iter_N.png

17. Next iteration:

Terrain Intelligence reads:

remaining_routes.json

instead of:

paths_1.json
