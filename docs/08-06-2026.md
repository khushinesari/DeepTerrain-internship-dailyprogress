# Agentic AI Learnings 
## basic pipeline of agentic ai systems 
- goal-> observe -> reason-> plan-> act->observe again-> update -> act again 
## details 
### goal:
#### optimal camera placements with maximum fov 
### perception:
#### builds an understanding of the environment , takes the following info 
- ground mask
- terrain mask 
- fov mask 
### world understanding :
#### makes a map taking i/p's from perception outputs i.e nothing but the reasoning stage 
### planning : 
#### predicts future possiblites 
- current position ->possible actions->future paths-> best soln choice 
- stage where algorithms for path planning used : A* , dijkstara's , Reverse Dijkstra's 
### action: 
#### agent exceution
- this is where LLM comes into picture which call for tools required , writes the code and search web
### feedback loop : 
#### after acting onto the environment it again iterates over and observes
## basic workflow :
- agent observes->agent reasons -> agent plans ->optimize and repeat
## Decision making :
1. agent generates actions
 ```
  actions = [move_north,
  move_south,
  move_east,
  move_west]
```
2. agent predict outcomes (state transition) 
   - if moves north hit wall
   - if moves west good
     1. rule based prediction - agent already knows the environment
        -outcome known as grid rules are known
        - current: (50,20)-> action: west -> predicted outcome:(50,19)
     2. simulation: agent runs the simulation(model-based planning)
        -FOV simulation
        -ray casting
        -coverage area calculation
     3. learned world models: use NN to learn past experience and predict future
     4. RL usage - change location or change orientation or both for defender
        -reward:
          - how close to goal?
          - how safe ?
      5. LLM's
         - current pos-> possible actions-> run fov & predict based on rewards 
3. score each outcome and select based on highest ranking (check when 2 have similar scores , where to go next )
4. execute
   - if west had highest score among 4 , move in west 
5. repeat
   - since environment changes it needs to start over the procedure again and the loop keeps repeating until goal reached
